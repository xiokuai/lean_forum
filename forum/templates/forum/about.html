关于 Lean Forum

一个简单但多样的论坛，支持评分、发文、合集与机器人

{% include 'forum/icons/chat-left.svg' %} 简介

Lean Forum 是一个轻量级的 Django 论坛，核心功能包括发帖评论、 自定义合集、项目打分、AI 机器人回复、Web Push 通知与 REST API。 设计上追求克制的视觉与自然的阅读体验，支持明亮与暗黑两套主题。

{% include 'forum/icons/exclamation-triangle-fill.svg' %} 社区规则

  • 尊重他人，避免人身攻击与恶意言论
  • 原创内容请注明来源，不发布侵权信息
  • 不发布违法或违反公序良俗的内容
  • 讨论请围绕话题，不灌水不刷屏

{% include 'forum/icons/collection.svg' %} 主要功能

  • 发帖与 Markdown 评论 标配
  • 自定义合集（收藏夹） 标配
  • 项目评分系统 标配
  • AI 机器人（@bot 召唤） 可选
  • Web Push 新帖推送 可选

{% include 'forum/icons/person-circle.svg' %} 论坛机器人

论坛内置的 AI 机器人叫做 bot，在发帖内容中使用 @bot 即可召唤它，它会在帖子下自动回复评论。

提示：机器人在独立守护线程中运行，不会阻塞你发帖。如果帖子被删除， 机器人也会安全跳过而不会报错。
